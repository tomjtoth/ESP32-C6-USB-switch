# Wireless USB switch

I found _1x type-A to 3x type-A_ wireless USB switches [on AliExpress](https://www.aliexpress.com/item/1005007419060826.html).

This project aims to recreate the same functionality with the help of the [_ESP32-C6 SuperMini_ board](https://www.aliexpress.com/item/1005008404515367.html) and _type-C_ connectors.
